# HANDOFF.md

## ¿Qué debe saber el/la siguiente responsable?
- El backend es FastAPI (Python), el frontend es React (Vite).
- La importación de propuestas funciona con archivos DOCX y URLs públicas de Google Docs.
- La base de datos es SQLite por defecto, ubicada en backend/app/database.py (o según configuración en .env).
- No hay autenticación ni despliegue en la nube implementados.

## Primeros pasos sugeridos
1. Leer CONTEXT.md y ARCHITECTURE.md para entender el objetivo y el diseño.
2. Seguir SETUP.md para levantar el entorno local.
3. Revisar RUNBOOK.md para tareas frecuentes y troubleshooting.
4. Consultar NEXT_STEPS.md para ver el backlog y prioridades.
5. Leer DECISIONS.md para entender decisiones técnicas clave.
6. Revisar CONTRIBUTING.md si se va a colaborar activamente.
