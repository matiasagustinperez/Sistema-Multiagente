## Troubleshooting común
- "No se puede acceder al frontend":
  - Verificar que npm run dev esté corriendo
  - Revisar puerto 5173
- "Backend no responde":
  - Revisar uvicorn y dependencias
  - Verificar variables en backend/.env
- "Error al importar Google Docs":
  - Verificar que el documento sea público
  - Revisar logs del backend
