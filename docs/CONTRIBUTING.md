# CONTRIBUTING.md

## Estilo de commits
- Mensajes claros, en español o inglés.
- Prefijo tipo: feat, fix, chore, docs, refactor, test, style.
- Ejemplo: feat: agregar importación desde Google Docs

## Ramas
- main: estable
- dev: desarrollo
- feature/<nombre>: nuevas features

## Pull Requests
- PRs contra dev, no contra main directo
- Describir cambios y motivación
- Referenciar issues/backlog si aplica

## Convenciones de código
- Python: PEP8, tipado, docstrings
- JS: ESLint, Prettier
